NOTSIP first-run setup

Configure the capabilities you intend to use. Secrets are written to the protected NOTSIP secret store; non-secret settings are versioned. Startup-only storage settings such as the database backend must be supplied before launching NOTSIP.

Core runtime

Database URL is startup-only. Set NOTSIP_DATABASE_URL before launch when PostgreSQL or another supported backend is required.

External integrations

Configured remote providers are required to use permitted HTTPS/public endpoints. Adapter credentials remain in the encrypted secret store.

Security, federation & updates

Unknown capabilities remain fail-closed. Higher numeric levels require higher autonomy/approval.
