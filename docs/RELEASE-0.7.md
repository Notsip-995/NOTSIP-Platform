# NOTSIP 0.7 release

Local validation: Python compileall + 8 pytest tests passed.

This release contains the consolidated Windows/Android runtime, persistent SQLite memory/world/task state, OpenAI-compatible model tool loop, autonomy policy, browser/web/email/calendar adapters, Windows execution/screenshot tools, Android pairing and command service, browser voice UI, and Windows install scripts.

No credentials are stored in the repository. External services and Android permissions remain configuration-gated; robotics, satellites, vehicles and building automation remain deferred until real targets exist.
